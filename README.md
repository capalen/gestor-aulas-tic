# 🏫 Gestor de Aulas y Recursos TIC

Un sistema web ligero, gratuito y en tiempo real para gestionar la reserva de aulas de informática, carros de portátiles, tabletas y espacios comunes en centros educativos. 

Diseñado específicamente para sustituir los antiguos cuadrantes de Excel, evitar solapamientos y facilitar la labor de los Coordinadores TIC.

## ✨ Características principales
* **Tiempo real:** Las reservas aparecen instantáneamente en todos los dispositivos conectados sin necesidad de recargar la página.
* **Control de aforo:** Aviso automático si se intenta reservar un aula con menos ordenadores que alumnos.
* **Recursos móviles:** Alertas automáticas para avisar a Conserjería al reservar carros de portátiles o tabletas.
* **Panel de Administración integrado:** Configuración visual de aulas, festivos, nombre del centro y fechas de curso (protegido por PIN).
* **Exportación de datos:** Descarga del registro histórico en formato CSV (Excel) para justificaciones del plan CoDiCe TIC u otros programas.
* **Costo cero:** Alojado en GitHub Pages con base de datos en Firebase (tier gratuito).

## 🚀 Cómo instalar este sistema en tu centro

Esta aplicación consta de un único archivo HTML que se conecta a una base de datos gratuita. Para utilizarlo, necesitas configurar tu propio entorno de Firebase y vincularlo al código.

Consulta el **Manual Completo de Instalación y Uso** incluido a continuación para ponerlo en marcha en menos de 10 minutos.
